What we did

We used two thermistors to measure the temperature inside and outside of a double pained window overnight. Our circuit, which was repeated for each thermistor was:
3.3v — 10kΩ — Analog Pin — Thermistor — GNDpin

The 10kΩ resistor, the Analog Pin and positive side of the thermistor were in parallel.

A measurement was taken every 21 seconds, and would average 10 readings from the thermistors.

Analytical Solution

Per our textbook Fundamental of Thermal-Fluid Sciences, kglass​=0.78 W/m⋅K and kair​=0.026 W/m⋅K. Additionally, as has been noted in lecture, air moving purely due to convection has a convection coefficient of approximately hi​=10 W/m2K, so that was used for inside. We also approximated the convection coefficient outside to be about ho​=25W/m⋅K based on this paper discussing International Window Standards for comparative U-value testing. The frame itself is presumed not to be part of the system because although its known not to be adiabatic, neither is the wall its set into.

from machine import ADC, Pin
import time
import math

# Setup ADC pins (GP26 = ADC0, GP27 = ADC1)
aPin = ADC(Pin(26))
bPin = ADC(Pin(27))

n = 3                # number of data points to average
R_fixed = 10000      # value of the series resistor
Vs = 3.28            # ADC reference voltage

# Steinhart–Hart Coefficients
A = 1.02228469e-03
B_SH = 2.53164557e-04
C = 4.70399105e-21

def adc_to_voltage(adc_value):
    return (adc_value * Vs) / 65535   # MicroPython ADC is 16-bit (0–65535)

def resistance_from_voltage(Vout):
    # voltage divider:  Vout = Vs * (R_ntc / (R_fixed + R_ntc))
    if Vout == 0:
        return float('inf')
    return R_fixed * (Vs / Vout - 1)

def steinhart_hart_temp(R):
    lnR = math.log(R)
    invT = A + B_SH * lnR + C * (lnR ** 3)
    T_kelvin = 1.0 / invT
    return T_kelvin - 273.15           # convert to °C

while True:
    aTotal = 0
    bTotal = 0
    
    # Take n readings
    for i in range(n):
        aTotal += aPin.read_u16()
        bTotal += bPin.read_u16()
        time.sleep(0.05)
    
    a_avg_adc = aTotal / n
    b_avg_adc = bTotal / n
    
    # Convert ADC → Voltage → Resistance
    aV = adc_to_voltage(a_avg_adc)
    bV = adc_to_voltage(b_avg_adc)
    aR = resistance_from_voltage(aV)
    bR = resistance_from_voltage(bV)
    
    # Convert Resistance → Temperature (°C)
    aTemp = steinhart_hart_temp(aR)
    bTemp = steinhart_hart_temp(bR)
    
    print("A sensor: {:.2f} °C,  R = {:.0f} Ω".format(aTemp, aR))
    print("B sensor: {:.2f} °C,  R = {:.0f} Ω".format(bTemp, bR))
    print("----")
    
    time.sleep(1)
